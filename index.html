Datenschutzerklärung

Family Smart Home Request Assistant · Stand: 30. Juli 2026

Dieser Assistent nimmt Smart-Home-Änderungswünsche auf und übermittelt sie nach ausdrücklicher Bestätigung als Issue an ein privates GitHub-Repository.

1. Verantwortlicher

Verantwortlich für diesen privaten Familien-Assistenten ist der Betreiber des GitHub-Kontos vohkts.

2. Zweck der Verarbeitung

Der Assistent strukturiert in Alltagssprache beschriebene Wünsche, Probleme und Verbesserungsvorschläge für ein privat betriebenes Home-Assistant-System. Vollständig geklärte Anforderungen können als GitHub-Issue an das private Projekt übergeben werden.

3. Verarbeitete Daten

Abhängig von der Eingabe können insbesondere folgende Inhalte verarbeitet werden:

  • Titel und Beschreibung des Änderungswunsches,
  • gewünschtes Verhalten, Bedingungen und Ausnahmen,
  • Akzeptanzkriterien, Priorität und erkennbare Risiken,
  • freiwillig genannte Informationen über Geräte, Räume oder Benachrichtigungsempfänger.

Es sollen keine Passwörter, Tokens, privaten Schlüssel, Zugangsdaten, vollständigen Gerätekennungen oder sonstigen Geheimnisse eingegeben werden.

4. Übermittlung an GitHub

Nach Bestätigung durch die Nutzerin oder den Nutzer werden der Issue-Titel und der strukturierte Inhalt an GitHub übermittelt und in einem privaten Repository gespeichert. Die Action ist ausschließlich dafür vorgesehen, neue Issues in diesem festgelegten Repository anzulegen.

5. Keine direkte Smart-Home-Steuerung

Der Assistent greift nicht direkt auf Home Assistant, Geräte, Live-Zustände, lokale Netzwerke, Secrets oder Deployment-Systeme zu. Er erstellt keine Branches, Pull Requests oder Deployments und führt keine Geräteaktionen aus.

6. Rechtsgrundlage und Nutzungskontext

Die Nutzung erfolgt im privaten und familiären Umfeld. Die Verarbeitung dient ausschließlich der Organisation und technischen Umsetzung freiwillig übermittelter Smart-Home-Anforderungen.

7. Speicherdauer

Übermittelte Anforderungen bleiben im privaten GitHub-Repository gespeichert, bis sie vom Repository-Inhaber gelöscht, geschlossen oder im Rahmen der Projektpflege archiviert werden.

8. Empfänger und externe Dienste

Für die Verarbeitung werden ChatGPT/OpenAI und GitHub genutzt. Für deren eigene Datenverarbeitung gelten zusätzlich die jeweiligen Datenschutzbestimmungen und Nutzungsbedingungen dieser Anbieter.

9. Betroffenenrechte

Betroffene Personen können Auskunft, Berichtigung oder Löschung der im privaten GitHub-Projekt gespeicherten Inhalte verlangen. Hierzu kann der Betreiber des Assistenten direkt kontaktiert werden.

10. Datensicherheit

Der verwendete GitHub-Zugang soll auf das notwendige Repository und die Berechtigung zum Erstellen von Issues beschränkt sein. Zugangsdaten werden nicht in öffentlichen Repository-Dateien gespeichert.

11. Änderungen dieser Erklärung

Diese Datenschutzerklärung kann angepasst werden, wenn sich Funktionsumfang, eingesetzte Dienste oder Verarbeitungszwecke ändern.

Privacy Policy

Family Smart Home Request Assistant · Last updated: July 30, 2026

This assistant collects smart-home change requests and, after explicit confirmation, submits them as issues to a private GitHub repository.

1. Controller

This private family assistant is operated by the owner of the GitHub account vohkts.

2. Purpose of processing

The assistant structures wishes, problems, and improvement requests for a privately operated Home Assistant system. Fully clarified requests may be transferred to the private project as GitHub issues.

3. Data processed

Depending on the user's input, the following information may be processed:

  • the title and description of the requested change,
  • desired behavior, conditions, and exceptions,
  • acceptance criteria, priority, and identified risks,
  • voluntarily provided information about devices, rooms, or notification recipients.

Users must not submit passwords, tokens, private keys, credentials, complete device identifiers, or other secrets.

4. Transfer to GitHub

After user confirmation, the issue title and structured request content are transmitted to GitHub and stored in a private repository. The action is intended solely to create new issues in that predefined repository.

5. No direct smart-home control

The assistant does not directly access Home Assistant, devices, live states, local networks, secrets, or deployment systems. It does not create branches, pull requests, or deployments and does not execute device actions.

6. Context of use

The assistant is used in a private family context. Processing is limited to organizing and preparing voluntarily submitted smart-home requests.

7. Retention

Submitted requests remain stored in the private GitHub repository until they are deleted, closed, or archived by the repository owner.

8. External services

ChatGPT/OpenAI and GitHub are used to provide this workflow. Their respective privacy policies and terms also apply to their own processing activities.

9. Data subject rights

Individuals may request access, correction, or deletion of information stored in the private GitHub project by contacting the operator of the assistant.

10. Security

The GitHub credential used by the action should be restricted to the required repository and issue-creation permission. Credentials are not stored in public repository files.

11. Changes

This policy may be updated if the assistant's functionality, services, or processing purposes change.

This page contains no analytics, advertising, cookies, or tracking scripts.
